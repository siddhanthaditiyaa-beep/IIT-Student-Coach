Features

Everything a good tutor does, with receipts

Pravesh is built to teach, not to hand out answers. Each feature is there so a student learns the idea and a teacher can verify what happened.

Hint first, solution second

Pick a problem and ask for a hint. The coach points at the first step and the likely mistake. The full worked solution is one click away when you need it.

Cited, grounded answers

Every explanation is built from retrieved concept notes. Click any source chip to read the exact note that the answer came from.

Chapter-wise mastery map

A recency-weighted score per chapter shows what you know and what is slipping. Red, amber and green bars update the moment you log an attempt.

Prerequisite-first plans

If Probability is weak because Permutations was never practised, the plan puts Permutations first. New students get an honest standard order, not a fake plan.

Safety guardrails

Prompt injection, live-exam requests, rank claims and off-topic questions are caught before any answer is generated, and the block is logged.

Snap a problem

Upload a photo of a problem. The text is read on your own machine, shown in an editable box, and only sent once you confirm it.

Teacher review and audit

Teachers unlock a protected panel with a key, log review actions and read the audit trail of everything the system did.

Weak-spot analysis

See which mistake types keep costing marks: sign errors, unit slips, missed cases. Fix the habit, not just the problem.

Fast and offline-ready

No LLM key needed. Without one, replies are built straight from the notes. With a key or a gateway, the same pipeline gets natural wording.

How it works

From a stuck problem to a better plan, in four steps

The same loop runs for every student, which keeps it explainable and easy to audit.

Ask or pick

Choose a problem, type a question or upload a photo. Guardrails screen the message first.

Retrieve

The coach finds the best concept notes for the detected chapter by keyword overlap.

Coach

You get a hint, a worked solution or an explanation, with citations and a confidence value.

Track and plan

Each attempt updates your mastery. The study plan re-ranks chapters and fixes foundations first.

Safety and trust

Built to be safe in a classroom

  • 1Blocks misuse early. Prompt injection, live-exam help and rank or intelligence claims never reach the answer step.
  • 2Stays on topic. Questions outside JEE PCM get a polite redirect, while basic maths and science are still welcome.
  • 3Honest about confidence. Every reply shows its sources and a confidence value, with a reminder to verify with a teacher.
  • 4Everything is logged. Actions land in an audit trail that only a teacher key can read.

FAQ

Questions people ask

Is any real student data used?+

No. The notes, questions and the 12 demo students are all synthetic and written for this project. Students are identified only by an alias such as STU-001.

Does it need an API key or the internet?+

No. Without a key, replies are built from the retrieved concept notes. If a gateway or an Anthropic or OpenAI key is configured, the same grounded context is sent to the model for more natural wording.

How is the mastery score calculated?+

Each concept starts at a neutral prior of 50 percent. Recent attempts count more, with each older attempt weighted 0.85 times the one after it. A chapter below 55 percent is treated as weak.

Is retrieval a vector database?+

No. It is a keyword-overlap retriever with chapter detection and synonyms, returning the top three notes with citations. It is small enough to explain in one sentence and can be swapped for embeddings later.

Can it replace a teacher?+

No, and it says so on every reply. It is a practice and revision companion. Teachers get a protected panel to review plans and an audit trail of system activity.

How do I run it on my own machine?+

Start the backend with py -m uvicorn app.main:app --port 8001, serve this folder with py -m http.server 5500, then open http://localhost:5500. The README has the full steps.
